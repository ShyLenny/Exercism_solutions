## 🎯 Why I'm Doing This
> **"This repository isn't about mastering every language—it's about enjoying the journey of discovering how different languages solve similar problems."**

I've picked up quite a few programming languages throughout school and college, but it's easy to forget things if you don't use them regularly.

This repository is my way of revisiting those languages, refreshing old concepts, and discovering new ones along the way.

I'm not trying to speedrun every language— I just want to have fun solving problems, appreciate what makes each language unique, and maybe use what I learn in future software and hardware projects.



## 📚 About This Repository

This repository is automatically synced with my Exercism account.

Every solution I submit on Exercism is pushed here automatically, making this a convenient place to revisit my solutions, track my progress, and look back at how my understanding of different programming languages evolves over time.
